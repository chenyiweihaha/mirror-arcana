# Changelog

## 0.3.0 — Selectable AI providers

- Keep DeepSeek and OpenAI credentials separately; select via AI_PROVIDER.
- OpenAI Responses API adapter with structured output and shared card validation.
- Display active service and retain per-turn provider labels; no automatic fallback.

## 0.2.0 — DeepSeek integration

- Server-side DeepSeek credentials, validated card references, interpretation and follow-up UI.
- Local configuration, friendly API errors and mock backend tests.
- No live API verification without the user’s key.

## 0.1.0 — Prototype

- Editable questions, touch shuffle, cut, one-card and three-card spreads.
- Fixed-deck selection, optional reversed cards, incremental reveal.
- Browser-local progress recovery and personal notes.
- 22 original symbolic placeholder cards with brief project-authored meanings.
- AI interpretation, in-app transcription, full licensed artwork and deck imports are not connected yet.
